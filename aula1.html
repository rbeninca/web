Parte 1 · História e Motivação

A Web antes do JavaScript

Em 1995, páginas Web eram documentos estáticos. O navegador recebia HTML e apenas exibia.

Uma página típica de 1994
pagina.html
<h1>Bem-vindo</h1>
<p>Esta é uma página estática.</p>
<p>Para atualizar, recarregue.</p>
O problema: qualquer interação exigia uma requisição ao servidor. Formulário inválido? Página recarrega. Menu aberto? Página recarrega.
O que era impossível sem JS

❌ Validar formulários no cliente

Todo dado precisava ir ao servidor para ser verificado.

❌ Mostrar/esconder elementos

Menus, abas e modais exigiam recarga de página.

❌ Reagir a eventos do usuário

Cliques, teclas e movimentos do mouse eram ignorados.

❌ Atualizar conteúdo dinamicamente

Não havia forma de alterar o conteúdo sem recarregar tudo.

A solução: uma linguagem que rodasse dentro do próprio navegador.
Parte 1 · História e Motivação

O nascimento do JavaScript

Em 1995, Brendan Eich foi contratado pela Netscape para criar uma linguagem de script para o navegador. A primeira versão foi escrita em aproximadamente 10 dias.

A história do nome
1
Mocha Nome interno durante o desenvolvimento.
2
LiveScript Primeiro nome público, ao ser lançado.
3
JavaScript Renomeado por decisão de marketing — Java estava na moda.
Atenção: Java está para JavaScript assim como carro está para carpete: os nomes parecem relacionados, mas são coisas completamente diferentes.
O primeiro programa interativo
index.html
<button onclick="alert('Olá!')">
Clique aqui
</button>
Isso mudou tudo: uma ação do usuário (clique) gera uma resposta imediata (alerta), sem nenhuma requisição ao servidor.
ECMAScript — o padrão oficial

O nome técnico da linguagem é ECMAScript. Por isso aparecem nomes como ES5 ES6 / ES2015 ES2023

ES6 (2015) — a grande virada

Trouxe let, const, arrow functions, classes, template strings e módulos.

Parte 1 · Peculiaridades da linguagem

Decisões históricas que você vai encontrar

Tipagem dinâmica

Uma variável pode receber valores de tipos diferentes ao longo do programa:

script.js
let valor = 10;
valor = "dez"; // string agora
valor = true; // boolean agora
Facilita scripts pequenos. Exige cuidado em programas maiores.
Coerção automática de tipos
script.js
console.log("5" + 2); // "52" (concatenou)
console.log("5" - 2); // 3 (converteu)
Use conversões explícitas para evitar surpresas:
Number("5")  ·  String(10)  ·  Boolean(1)
var → let e const

O var original tinha comportamento de escopo confuso. O ES6 resolveu isso:

const

use sempre que possível

Valor não pode ser reatribuído. Deixa a intenção clara.

const pi = 3.14159;

let

quando o valor muda

Valor pode ser reatribuído. Escopo de bloco.

let contador = 0;
contador++;

var

evitar em código novo

Escopo de função, comportamento histórico confuso.

Parte 2 · Entrando na linguagem

Onde escrever JavaScript?

Há três formas de incluir JavaScript em uma página HTML.

1

Atributo HTML

Diretamente no elemento. Simples, mas mistura estrutura com comportamento.

<button
onclick="alert('Olá!')"
>Clique</button>
Não recomendado para projetos reais.
2

Tag <script>

Código JS dentro do HTML, geralmente antes de fechar o <body>.

<script>
console.log(
"Olá!"
);
</script>
Bom para aprender e para páginas simples.
3

Arquivo externo

JS em arquivo separado .js, referenciado no HTML.

index.html
<script src="script.js"></script>
script.js
console.log("Olá!");
Recomendado para projetos organizados.
Parte 3 · Variáveis

Variáveis: armazenando valores

Variáveis são espaços nomeados na memória para guardar valores durante a execução do programa.

let — valor pode mudar
script.js
let contador = 0;
contador = contador + 1;
console.log(contador); // 1
const — valor fixo
script.js
const pi = 3.14159;
console.log(pi);
const nome = "Ana";
nome = "Maria"; // ❌ Erro!
Boas práticas de nomenclatura

❌ Evitar

let x = "João";
let a = 20;
let v = true;

✓ Preferir

let nomeAluno = "João";
let idadeAluno = 20;
let aprovado = true;
camelCase — padrão JavaScript
nomeCompleto   mediaFinal   quantidadeAlunos
Regra simples: const sempre que possível · let quando o valor muda · nunca var.
Parte 4 · Tipos de Dados

Tipos de dados em JavaScript

O tipo determina o que o valor é e o que se pode fazer com ele.

🔢

number

Inteiros e decimais. Um único tipo para ambos.

let idade = 18;
let altura = 1.75;
📝

string

Texto entre aspas simples, duplas ou crase.

let nome = "Ana";
let cidade = 'SC';
⚖️

boolean

Apenas dois valores possíveis.

let aprovado = true;
let pago = false;
❓

undefined

Variável declarada, mas sem valor atribuído ainda.

let endereco;
→ undefined
∅

null

Ausência intencional de valor. O programador colocou "vazio" de propósito.

let telefone = null;
🔍

typeof

Operador que retorna o tipo de um valor como string.

typeof 42 // "number"
typeof "olá" // "string"
typeof true // "boolean"
Curiosidade histórica: typeof null retorna "object". Isso é um bug antigo da linguagem que foi mantido por compatibilidade — null não é um objeto.
Parte 4 · Tipos de Dados

Trabalhando com numbers e strings

Operações com numbers
script.js
let soma = 10 + 5; // 15
let sub = 10 - 5; // 5
let mult = 10 * 5; // 50
let div = 10 / 4; // 2.5
let resto = 10 % 3; // 1
let pot = 2 ** 8; // 256
let nota1 = 8, nota2 = 7;
let media = (nota1 + nota2) / 2;
console.log(media); // 7.5
Strings — concatenação e template strings
script.js
// aspas duplas ou simples
let nome = "Maria";
let cidade = 'Blumenau';
// concatenação com +
console.log("Olá, " + nome);
← Olá, Maria
// template string com crase ✓
let idade = 18;
console.log(
`${nome} tem ${idade} anos.`
);
← Maria tem 18 anos.
Prefira template strings (crase + ${}) à concatenação com + — são mais legíveis.

Parte 5 · Estruturas de Seleção

if / else — tomando decisões

Operadores relacionais
>maior que
<menor que
>=maior ou igual
<=menor ou igual
Comparação de igualdade
===igual sem conversão de tipo ✓
!==diferente sem conversão de tipo ✓
==igual com conversão (evitar)
!=diferente com conversão (evitar)
console.log(5 == "5"); // true ⚠
console.log(5 === "5"); // false ✓
if / else if / else
script.js
let nota = 8;
if (nota >= 9) {
console.log("Excelente");
} else if (nota >= 6) {
console.log("Aprovado");
} else {
console.log("Reprovado");
}
Operadores lógicos
let idade = 20;
let temCarteira = true;
if (idade >= 18 && temCarteira) {
console.log("Pode dirigir");
}
&& E lógico  ·  || OU lógico  ·  ! NÃO lógico
Parte 5 · Estruturas de Seleção

switch — múltiplas possibilidades

Use switch quando um mesmo valor pode ter muitos casos distintos — é mais organizado que vários if.

script.js
let dia = 2;
switch (dia) {
case 1:
console.log("Domingo");
break;
case 2:
console.log("Segunda-feira");
break;
case 3:
console.log("Terça-feira");
break;
default:
console.log("Dia inválido");
}
← Segunda-feira
Anatomia do switch

switch (expressão)

O valor a ser comparado contra os case.

case valor:

Bloco executado quando a expressão é igual ao valor.

break

Para a execução. Sem break, os casos seguintes também executam (fall-through).

default

Executado quando nenhum case foi satisfeito. Equivale ao else.

Use switch quando: um único valor pode assumir vários valores discretos conhecidos. Para condições com intervalos (>=, <=), prefira if/else if.

Parte 6 · Estruturas de Repetição

for — quando sabemos quantas vezes repetir

Anatomia do for
for (inicialização; condição; atualização) {
// bloco repetido
}

Inicialização

Executa uma vez antes de começar. Ex: let i = 1

Condição

Testada antes de cada iteração. Ex: i <= 10

Atualização

Executa ao final de cada iteração. Ex: i++

Exemplos
script.js
// imprimir de 1 a 5
for (let i = 1; i <= 5; i++) {
console.log(i);
}
← 1 2 3 4 5
// listar alunos
for (let i = 1; i <= 5; i++) {
console.log(`Aluno ${i}`);
}
← Aluno 1 Aluno 2 …
// somar de 1 a 100
let soma = 0;
for (let i = 1; i <= 100; i++) {
soma += i;
}
console.log(soma);
← 5050
Parte 6 · Estruturas de Repetição

while e do while

while — testa antes de executar
script.js
let contador = 1;
while (contador <= 5) {
console.log(contador);
contador++;
}
← 1 2 3 4 5
do while — executa pelo menos uma vez
script.js
let numero = 1;
do {
console.log(numero);
numero++;
} while (numero <= 5);
do while sempre executa o bloco ao menos uma vez, pois a condição é verificada depois.
⚠️ Cuidado: loop infinito
ERRO — não rode!
// ❌ i nunca muda → loop infinito
let i = 1;
while (i <= 10) {
console.log(i);
// i++ esquecido!
}
Correto ✓
let i = 1;
while (i <= 10) {
console.log(i);
i++; // garantir progresso
}
Regra: sempre garanta que a condição do loop eventualmente se tornará falsa — caso contrário, o programa trava.

Parte 7 · Funções

Funções: blocos de código reutilizáveis

Funções evitam repetição e organizam o código em unidades com propósito bem definido.

Sem função — repetição
let media1 = (8 + 7) / 2;
console.log(media1);
let media2 = (5 + 9) / 2;
console.log(media2);
Com função — organizado ✓
script.js
function calcularMedia(nota1, nota2) {
return (nota1 + nota2) / 2;
}
console.log(calcularMedia(8, 7)); // 7.5
console.log(calcularMedia(5, 9)); // 7
Parâmetros e retorno
script.js
// sem parâmetros
function saudacao() {
console.log("Olá!");
}
saudacao();
// com parâmetros
function saudacao(nome) {
console.log(`Olá, ${nome}!`);
}
saudacao("Ana");
← Olá, Ana!
// com retorno
function somar(a, b) {
return a + b;
}
let resultado = somar(10, 5);
console.log(resultado); // 15
Sem return explícito, a função retorna undefined. Use return sempre que a função precisar produzir um valor.
Parte 7 · Funções

Arrow functions — sintaxe moderna

Introduzidas no ES6. Sintaxe mais compacta para escrever funções.

Declaração tradicional
function somar(a, b) {
return a + b;
}
function saudacao(nome) {
return `Olá, ${nome}!`;
}
Arrow function — equivalente
// com chaves e return
const somar = (a, b) => {
return a + b;
};
// expressão única: sem chaves nem return
const somar = (a, b) => a + b;
const saudacao = nome =>
`Olá, ${nome}!`;
Um parâmetro só → parênteses opcionais.
Expressão única → sem chaves e o valor é retornado automaticamente.
Recomendação pedagógica: aprenda primeiro com function tradicional. Use arrow functions quando se sentir confortável com os conceitos de parâmetro e retorno.
Parte 8 · Exercício Integrador

Classificador de alunos

Combine tudo que aprendeu: variáveis, tipos, funções e seleção.

Versão básica
script.js
function calcularMedia(nota1, nota2) {
return (nota1 + nota2) / 2;
}
const nome = "Ana";
const nota1 = 8;
const nota2 = 7;
const media = calcularMedia(nota1, nota2);
if (media >= 6) {
console.log(`${nome} aprovado com média ${media}.`);
} else {
console.log(`${nome} reprovado com média ${media}.`);
}
← Ana aprovado com média 7.5.
Versão avançada — lista de alunos
script.js
const alunos = [
{ nome: "Ana", nota1: 8, nota2: 7 },
{ nome: "Carlos", nota1: 5, nota2: 6 },
{ nome: "Maria", nota1: 9, nota2: 10 }
];
function calcularMedia(n1, n2) {
return (n1 + n2) / 2;
}
for (let aluno of alunos) {
const m = calcularMedia(aluno.nota1, aluno.nota2);
const status = m >= 6 ? "aprovado" : "reprovado";
console.log(`${aluno.nome}: ${status} (${m})`);
}
← Ana: aprovado (7.5)
← Carlos: reprovado (5.5)
← Maria: aprovado (9.5)
Para avançados: for...of percorre arrays. condição ? a : b é o operador ternário — equivale a um if/else inline.
